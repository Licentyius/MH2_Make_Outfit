A short remark about filenames

Linux:

* is case dependent
* use ASCII only to avoid problems
* forbidden: /, Null

Windows:

* is case independent
* use ASCII only to avoid problems
* forbidden: < > : " / \ | ? * (ascii 0-31)

Conclusion:
the forbidden letters are the one from windows
internal representation: lowercase, URL path representation ("/")

"normalization":
        difference case dependent vs. case independent will stay (Linux/Windows)
        separator is "/"

length is not considered component is 255 and max-path length on linux
is 4096 bytes (windows 32k)

IMPORTANT
* the internal reposity (dbcache) contains URL names only.
* reload this cache (-r) at least once for a mesh
